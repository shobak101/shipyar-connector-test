# 🔥 Habit Streak Tracker

A single-file habit tracker with streaks, built in plain HTML/CSS/JS.

## Features
- Add habits and check them off daily
- Tracks **current streak** and **best streak** per habit
- 7-day dot calendar per habit for a quick visual history
- Input clears and refocuses automatically after adding
- Data persists in `localStorage` — no server needed
- Dark UI

## How to run
Open `index.html` in any modern browser. That's it.
