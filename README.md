# Tip Calculator

A clean, minimal single-page tip calculator.

## Features

- Bill amount input with decimal support
- Tip % slider (0–30%) with 15/18/20/25% quick-select buttons
- Party size stepper (1–20 people)
- Live per-person total, total tip, and total bill display

## How to run

Open `index.html` in any browser — no server, no build step, no dependencies.

```
open index.html
```

Works fully offline.
