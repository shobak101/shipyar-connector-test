# Stopwatch

A single-page stopwatch with start/stop, lap recording, and split times.

## Features
- Large monospace time display (HH:MM:SS.cs)
- Start / Stop / Lap / Reset controls
- Lap list with per-lap split time + running total
- Best lap highlighted green, slowest highlighted red
- Clean dark minimal design — zero dependencies

## How to run

Open `index.html` directly in any browser — no server needed.

```
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```
